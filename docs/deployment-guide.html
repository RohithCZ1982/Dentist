Deploy DentalAI to Production

Step-by-step guide to host the React frontend on Vercel and the FastAPI backend on Render — both for free.

Frontend → Vercel (Free)
Backend → Render (Free)
AI → Groq API
🗺

Architecture Overview

U
User uploads dental X-ray in browser Vercel · localhost:5173
→
React app sends image to FastAPI via POST /analyze/* HTTP multipart/form-data
B
FastAPI backend receives image, calls Groq Vision API Render · localhost:8001
→
Groq runs Llama 4 Scout vision model, returns JSON findings Groq API
✓
Frontend renders overlay markers + findings sidebar React Canvas
ℹ The frontend and backend are deployed as two separate services. They communicate over HTTPS. CORS is configured on the backend to allow requests only from your Vercel domain.
✓

Push to GitHub

All deployments pull from your GitHub repository. Set it up first.

⚠ Make sure .gitignore is in place before pushing — it excludes your .env file with the Groq key from the repository.
  1. 1

    Initialise git in the project root

    bash
    # From c:/Softwares/Dentist
git init
git add .
git commit -m "Initial commit: DentalAI application"
  2. 2

    Create a new GitHub repository

    Go to github.com/new, name it dental-xray-ai, set to Public or Private, do not add a README (your code already has one).

  3. 3

    Push your code

    bash
    git remote add origin https://github.com/YOUR_USERNAME/dental-xray-ai.git
git branch -M main
git push -u origin main
    ✓ Verify on GitHub that backend/.env is not present in the repo — only .env.example should be there.

Deploy Backend → Render

🟢
Render
Free web services with 750 hrs/mo. Supports Python natively. Auto-deploys from GitHub.
⚡
Free Tier Limits
Service sleeps after 15 min idle. First request after sleep ~30s. Upgrade to $7/mo to remove.
  1. 1

    Create a new Web Service

    Log in to render.com → click New + → select Web Service.

  2. 2

    Connect your GitHub repository

    Select Connect a GitHub account → authorize Render → choose your dental-xray-ai repository.

  3. 3

    Configure the service

    Fill in these fields on the setup page:

    FieldValue
    Namedental-xray-api
    Root Directorybackend
    RuntimePython 3
    Build Commandpip install -r requirements.txt
    Start Commanduvicorn main:app --host 0.0.0.0 --port $PORT
    Instance TypeFree
  4. 4

    Add Environment Variables

    Scroll down to Environment Variables and add:

    KeyValue
    GROQ_API_KEY gsk_your_actual_groq_key Required
    FRONTEND_URL Leave blank for now — fill after Vercel deploy Later
  5. 5

    Deploy and copy your URL

    Click Create Web Service. Render will build and deploy. Watch the logs — look for:

    render logs
    INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:10000

    Your backend URL will be: https://dental-xray-api.onrender.com
    (exact name depends on what you entered — check the top of the Render dashboard)

    ✓ Test it by visiting https://your-service.onrender.com/health in your browser — you should see {"status":"ok"}.
3

Deploy Frontend → Vercel

▲
Vercel
Best-in-class static/Vite hosting. Free tier has unlimited deploys and global CDN.
🔄
Auto Deploy
Every git push to main triggers a new deployment automatically.
  1. 1

    Import your repository

    Go to vercel.com/new → click Import Git Repository → connect GitHub → select dental-xray-ai.

  2. 2

    Set Root Directory to frontend

    Click Edit next to Root Directory and type frontend. This tells Vercel to only build the React app, not the whole repo.

  3. 3

    Confirm build settings

    Vercel auto-detects Vite. Confirm these values:

    FieldValue
    FrameworkVite
    Build Commandnpm run build
    Output Directorydist
  4. 4

    Add Environment Variable

    Click Environment Variables and add:

    KeyValue
    VITE_API_URL https://dental-xray-api.onrender.com
    Use your actual Render URL from Step 2    		 Required
  5. 5

    Deploy

    Click Deploy. Vercel builds and deploys in ~60 seconds. Copy your URL — e.g. https://dental-ai.vercel.app.

    ✓ You can set a custom domain in Vercel → Project Settings → Domains for free.
4

Connect Frontend ↔ Backend

Now that both services are live, update the backend CORS to allow your Vercel domain.

  1. 1

    Add FRONTEND_URL to Render

    In Render → your service → Environment tab → add/update:

    KeyValue
    FRONTEND_URL https://dental-ai.vercel.app
    Your actual Vercel URL
  2. 2

    Redeploy the backend

    In Render → Manual Deploy → Deploy latest commit. This restarts the server and picks up the new FRONTEND_URL so CORS is updated.

  3. 3

    Test end-to-end

    Open your Vercel URL in a browser, upload a dental X-ray, and click Analyze X-Ray. You should see AI findings appear in the sidebar.

    ⚠ First analysis after Render idles may take ~30 seconds on the free tier. This is normal — the server is waking up. Subsequent calls are fast.

Troubleshooting

❌ CORS error in browser console

The backend is not allowing your Vercel domain. Check: (1) FRONTEND_URL is set correctly in Render env vars, (2) backend was redeployed after adding it.

⏳ Analysis takes 30+ seconds

Render free tier cold start. Normal on first request after 15 min idle. Either wait or upgrade to a paid Render plan ($7/mo).

❌ 401 Unauthorized from backend

Invalid or missing GROQ_API_KEY in Render. Go to Render → Environment → verify the key is correct and redeploy.

❌ Vercel build fails

Check that Root Directory is set to frontend in Vercel project settings, not the repo root.

⚠ Findings return empty

The image may not be a dental X-ray, or the Groq model couldn't parse it. Try a clearer bitewing or periapical X-ray image. Check Render logs for raw model output.
